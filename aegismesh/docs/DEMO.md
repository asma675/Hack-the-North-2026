# 90-second judge demo

Open `/app/judge` after using the **Launch Judge Demo** button on the landing page.

1. **Healthy** — show the real/simulated provider badges and green edge status.
2. **False alarm** — trigger CPU/disk activity. The swarm investigates; OpenAI Evidence Court concludes the nightly backup explains it and recommends **NO ACTION**.
3. **Breach** — trigger failed logins + a successful login + a novel outbound connection. openJiuwen dispatches specialists and the UI shows their real/shortened messages.
4. **Challenge** — Skeptic pushes against the easy backup explanation; Evidence Court adjudicates the competing evidence.
5. **Poison** — inject the poisoned runbook. The telemetry agent requests a capability it does not possess; Aegis Gate blocks it, trust falls, and the mascot is quarantined while the mission continues.
6. **Safe remediation** — Evidence Court recommends the least-destructive containment action.
7. **Human gate** — NFC/approval satisfies the second key; a short-lived signed execution capability is issued.
8. **Physical finale** — Aegis Edge verifies signature, expiry, target and replay state before actuating the safe low-voltage relay/simulation.
9. **Replay** — finish on incident replay and blocked-action metrics.

Suggested closing line: **“We didn’t build agents that always get things right. We built the control layer that keeps production safe when they don’t.”**
